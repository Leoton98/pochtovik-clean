# 🧪 Тестирование мульти-девайс функциональности

## 📋 Что было добавлено

### Новый UI компонент - DevicesView
Удобный интерфейс для просмотра и управления доверенными устройствами.

**Возможности:**
- ✅ Просмотр списка всех зарегистрированных устройств
- ✅ Информация по каждому устройству:
  - Название (Samsung Galaxy, Windows PC и т.д.)
  - Платформа (mobile/web/desktop)
  - Дата регистрации
  - Последняя активность
  - Статус (онлайн/офлайн)
- ✅ Удаление устройств (кроме текущего)
- ✅ Визуальное определение типа устройства по иконкам
- ✅ Индикатор текущего устройства

## 🚀 Как тестировать

### 1. Запуск сервера

```bash
cd name-server-v2
npm start
```

Сервер запустится на `http://localhost:3001`

### 2. Запуск клиента

```bash
cd client
npm start
```

Клиент откроется в браузере (обычно `http://localhost:3000`)

### 3. Сценарий тестирования

#### Шаг 1: Регистрация первого пользователя

1. Откройте браузер (Chrome/Firefox/Edge)
2. Зарегистрируйтесь как `alice` с паролем `123456`
3. Запомните displayName (например, "Alice Test")

**Что происходит:**
- Генерируется пара ключей RSA
- Создаётся deviceId = `device-{timestamp}-{random}`
- Устройство автоматически регистрируется на сервере
- Вы попадаете в чат

#### Шаг 2: Проверка устройств

1. Нажмите кнопку **"Настройки"** (в чате)
2. Нажмите кнопку **"Управление устройствами"**
3. Вы увидите список из 1 устройства:
   - Ваше текущее устройство
   - Помечено как "Текущее"
   - Тип: Desktop (или Mobile если с телефона)

**Ожидаемый результат:**
```
Мои устройства
└── Desktop/Web (Текущее)
    Платформа: web
    Зарегистрировано: 15 марта 2026, 14:30
    Активность: 15 марта 2026, 14:30
```

#### Шаг 3: Регистрация второго устройства (режим инкогнито)

1. Откройте **режим инкогнито** в браузере (Ctrl+Shift+N)
2. Перейдите на `http://localhost:3000`
3. Войдите как `alice` с тем же паролем `123456`

**Что происходит:**
- Генерируется НОВЫЙ deviceId
- Приватный ключ загружается из localStorage (если есть) или генерируется новый
- Новое устройство регистрируется на сервере

#### Шаг 4: Проверка списка устройств

1. В режиме инкогнито зайдите в **Настройки** → **Управление устройствами**
2. Теперь вы видите 2 устройства:
   - Первое (Desktop/Web)
   - Второе (Desktop/Web - Инкогнито)

**Ожидаемый результат:**
```
Мои устройства (2)
├── Desktop/Web (Текущее)
│   Платформа: web
│   Зарегистрировано: 15 марта 2026, 14:30
└── Desktop/Web (Текущее)
    Платформа: web
    Зарегистрировано: 15 марта 2026, 14:35
```

#### Шаг 5: Удаление устройства

1. В режиме инкогнито нажмите кнопку удаления (🗑️) на первом устройстве
2. Подтвердите удаление
3. Первое устройство исчезнет из списка

**Важно:** Кнопка удаления недоступна для текущего устройства!

#### Шаг 6: Проверка на основном устройстве

1. Вернитесь в обычный браузер (не инкогнито)
2. Обновите страницу (F5)
3. Зайдите в **Настройки** → **Управление устройствами**
4. Вы должны увидеть только одно устройство (второе было удалено)

## ⚠️ Возможные проблемы

### Проблема 1: Устройства не загружаются

**Решение:**
1. Проверьте что сервер запущен (`npm start` в name-server-v2)
2. Проверьте URL сервера в настройках (должен быть `http://localhost:3001`)
3. Нажмите кнопку "Проверить" в настройках

### Проблема 2: Ошибка при удалении

**Текст ошибки:** "Cannot read properties of null"

**Решение:**
1. Обновите страницу
2. Убедитесь что удаляете НЕ текущее устройство
3. Проверьте консоль на наличие ошибок

### Проблема 3: Два устройства показываются как "Текущее"

**Причина:** Оба устройства используют один localStorage

**Решение:** Используйте режим инкогнито или разные браузеры
