# 📋 Инструкция по добавлению логотипа

## Куда положить файл логотипа

Поместите ваш файл с логотипом в папку `client/public/` и переименуйте его в `logo.png`

**Путь:** `c:\Users\pkleontev\Documents\Pochtovik\client\public\logo.png`

## Требования к логотипу

### Формат:
- **Файл:** PNG (рекомендуется) или SVG
- **Название:** `logo.png`
- **Размер:** Квадратный (например, 512x512px или 1024x1024px)
- **Фон:** Прозрачный или однотонный

### Где отображается:

1. **Экран входа (LoginView)**
   - Размер: 120x120px
   - По центру над заголовком "Почтовик"
   - С тенью для объёма

2. **Хедер чата (ChatView)**
   - Размер: 40x40px
   - Слева от названия "Почтовик"
   - В верхней панели слева

## Как заменить

1. Скопируйте ваш файл логотипа
2. Вставьте в папку `client/public/`
3. Переименуйте в `logo.png` (если нужно)
4. Перезапустите приложение

## Пример структуры:

```
Pochtovik/
├── client/
│   ├── public/
│   │   ├── index.html
│   │   └── logo.png          ← Ваш логотип здесь
│   └── src/
│       └── ...
└── ...
```

## Если логотип не отображается:

1. Проверьте что файл называется точно `logo.png`
2. Проверьте путь: `client/public/logo.png`
3. Перезапустите dev-сервер
4. Очистите кэш браузера (Ctrl+Shift+R)

---

**Готово!** Логотип будет отображаться на всех экранах приложения! 🎨
