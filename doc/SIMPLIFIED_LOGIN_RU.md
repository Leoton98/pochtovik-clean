## 💡 Как это работает

### 1. **Автоматическое использование сохранённых данных**

Приложение автоматически:
- ✅ Загружает сохранённый приватный ключ из Electron Store
- ✅ Использует сохранённые настройки облака
- ✅ Подключается к бакету без ввода данных

### 2. **Если нет сохранённых данных**

При первом входе:
- ✅ Приложение предложит импортировать приватный ключ
- ✅ Или использовать импорт конфигурации
- ✅ После первого входа все данные сохраняются

### 3. **Расширенные настройки (опционально)**

По клику на "▶ Настройки подключения":
- Yandex Cloud Bucket (можно не заполнять)
- URL сервера имён
- Access Key ID
- Secret Access Key

⚠️ **Все поля опциональны!** Используются сохранённые значения.

## 🔐 Безопасность

### Что сохраняется:

| Данные | Где | Зачем |
|--------|-----|-------|
| Приватный ключ | Electron Store | Для автоматического входа |
| Конфигурация | Electron Store | Для подключения к облаку |
| Secret Access Key | Electron Store (зашифрован) | Для доступа к бакету |

### Защита:

✅ **Локальное хранение** - данные только на устройстве  
✅ **Шифрование** - Secret Key шифруется  
✅ **Автоматическая подстановка** - не нужно вводить вручную  
✅ **Импорт/Экспорт** - безопасный перенос конфигов

## ⚙️ Технические детали

### Автоматическая загрузка ключа:

```javascript
// При входе приложение автоматически:
let privateKeyPem = await window.electronAPI.store.get('privateKey');

if (!privateKeyPem) {
  // Если нет сохранённого, предлагает импортировать
  const keyResult = await window.electronAPI.privateKeyImport();
  privateKeyPem = keyResult.privateKey;
}

// Использует ключ для входа
await onLogin(userId, privateKeyPem, config);
```

### Использование сохранённой конфигурации:

```javascript
// При инициализации:
const cloud = new YandexCloudClient({
  bucket: user.bucket || savedBucket,      // Из сохранения
  accessKeyId: user.accessKeyId || savedAccessKeyId,
  secretAccessKey: user.secretAccessKey || savedSecretAccessKey,
  endpoint: user.endpoint || 'https://storage.yandexcloud.net'
});
```

## ❓ Частые вопросы

### Q: А если я хочу ввести другой приватный ключ?

**A:** Нажмите "👤 Войти под другим аккаунтом" → "📥 Импорт конфига" → выберите файл ключа.

---

### Q: Где хранятся мои данные?

**A:** В Electron Store:
- Windows: `%APPDATA%\Pochtovik\config.json`
- macOS: `~/Library/Application Support/Pochtovik/config.json`
- Linux: `~/.config/Pochtovik/config.json`

---

### Q: Можно ли использовать разные бакеты на разных устройствах?

**A:** Да! В настройках подключения укажите нужный bucket. Но лучше использовать один для синхронизации.

---

### Q: Что делать, если автовход не сработал?

**A:** 
1. Проверьте, что вы ранее регистрировались/входили
2. Попробуйте "📥 Импорт конфига"
3. Если не помогло - войдите вручную через "Настройки подключения"
