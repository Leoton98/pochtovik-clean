# 🚀 Развёртывание кроссплатформенного мессенджера

## 📋 Что сделано

### ✅ Архитектура
```
┌──────────────┐                          ┌──────────────┐
│   Клиент 1   │◄──────WebSocket─────────►│ Name Server  │
│   (Android)  │                          │   (Railway)  │
└──────────────┘                          └──────────────┘
       ▲                                         │
       │                                         │
       │           Yandex Cloud                  │
       └─────────────────────────────────────────┘
       
┌──────────────┐                          ┌──────────────┐
│   Клиент 2   │◄──────WebSocket─────────►│   Firebase   │
│   (Desktop)  │                          │   (Push)     │
└──────────────┘                          └──────────────┘
```

### ✅ Компоненты

1. **Name Server v2** (`name-server-v2/`)
   - WebSocket для real-time связи
   - Индикаторы онлайн/офлайн
   - Поддержка мульти-девайс

2. **RealtimeClient** (`client/src/services/RealtimeClient.js`)
   - Автопереподключение
   - Heartbeat для поддержания соединения
   - Обработка статусов

3. **Yandex Cloud Storage**
   - Хранение зашифрованных сообщений
   - Общий бакет для всех пользователей

## 🔧 Установка и запуск

### Вариант 1: Локальная разработка

```bash
# Терминал 1: Name Server v2
cd name-server-v2
npm install
npm run dev
# Сервер запустится на http://localhost:3001

# Терминал 2: Клиент
cd client
npm install
npm start
# Приложение запустится на http://localhost:3000
```

### Вариант 2: Деплой на Railway (рекомендуется)

1. **Установите Railway CLI:**
```bash
npm i -g @railway/cli
```

2. **Залогиньтесь:**
```bash
railway login
```

3. **Создайте проект:**
```bash
cd name-server-v2
railway init
railway up
```

4. **Настройте переменные окружения:**
```bash
railway variables set PORT=3001
```

5. **Получите URL:**
```bash
railway domain
# Пример: pochtovik-server.railway.app
```

### Вариант 3: Деплой на Vercel

1. **Установите Vercel CLI:**
```bash
npm i -g vercel
```

2. **Задеплойте:**
```bash
cd name-server-v2
vercel --prod
```

## 🛠️ Решение проблем

### Проблема 1: WebSocket не подключается

**Симптомы:**
- Ошибка "WebSocket not connected"
- Нет индикатора онлайн

**Решение:**
1. Проверьте что сервер доступен
2. Откройте консоль браузера (F12)
3. Посмотрите логи подключения

### Проблема 2: Сообщения не доставляются

**Симптомы:**
- Сообщение отправлено но не получено
- Статус не меняется

**Решение:**
1. Проверьте Yandex Cloud credentials
2. Убедитесь что бакет существует
3. Проверьте права доступа к бакету

### Проблема 3: Сервер засыпает

**Симптомы:**
- Медленный ответ после простоя
- Таймауты подключения

**Решение:**
- Перейдите с Render на Railway/Vercel
- Или настройте ping каждые 5 минут
